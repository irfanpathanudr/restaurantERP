# KOT Menu Quick Start Guide for Waiters

## New Menu Interface - How to Use

### Overview
The KOT menu selection has been redesigned to show **more items on screen** and make order taking **faster and easier**.

---

## Main Features

### 1. Category Sidebar (Left Side)
```
┌──────────┐
│ All Items│ ← Tap to see all menu items
│          │
│ Starters │ ← Tap to filter by category
│          │
│Main Course│
│          │
│ Desserts │
│          │
│ Beverages│
└──────────┘
```

**How to Use:**
- Tap any category to filter menu items
- All categories are always visible (no scrolling needed)
- Currently selected category is highlighted in orange
- Tap "All Items" to see everything

---

### 2. View Toggle (Top Right)

#### Grid View [⊞] (Default)
```
┌────┐ ┌────┐ ┌────┐
│ 🍔 │ │ 🍕 │ │ 🍗 │

│$20 │ │$30 │ │$25 │

│ 🍗  Chicken               $25 [+]│

```
- **When to use:** Rush hours, experienced waiters
- **Best for:** Speed, maximum items visible
- Horizontal layout with quick add buttons

## Step-by-Step: Taking an Order

### Method 1: Quick Order (List View - Fastest)
1. Tap **List icon** [☰] at top right
2. Select **category** from left sidebar
3. Scroll through items
4. Tap **[+] button** on each item to add
5. Quantity badge appears on item
6. Tap **[+]** again to increase quantity
7. Review cart at bottom
8. Tap **"Send to Kitchen"**

**⏱️ Time: 10-15 seconds for 5 items**

---

### Method 2: Visual Browse (Grid View)
1. Keep **Grid icon** [⊞] selected (default)
2. Select **category** from left sidebar
3. Tap **anywhere on item card** to add
4. Green badge shows quantity added
5. Tap item again to add more
6. Check cart summary at bottom
7. Tap **"Send to Kitchen"**

**⏱️ Time: 15-20 seconds for 5 items**

## Common Tasks

### Adding Items with Variants (Sizes)
1. Tap on item (e.g., Pizza)
2. **Size selection modal** appears
3. Choose: Small / Medium / Large
4. Item added to cart with selected size
5. Cart shows: "Pizza (Medium)"

### Searching for Items
1. Tap **search bar** at top
2. Type item name (e.g., "chicken")
3. Results filter instantly
4. Tap **X** to clear search

### Checking What's in Cart
- Look at **green badges** on menu items (shows quantity)
- Scroll to **bottom of screen** for cart summary
- Shows: "5 items in cart" + total amount

### Modifying Cart Before Sending
1. Scroll to cart at bottom
2. See all items with quantities
3. Tap **[-]** to decrease quantity
4. Tap **[+]** to increase quantity
5. Items with 0 quantity are removed

### Switching Categories Quickly
- Categories are **always visible** on left
- No need to scroll
- Just **tap category name**
- Menu items update instantly

## Pro Tips

### 🚀 Speed Tips
1. **Use List View during rush hours** - you'll see more items
2. **Learn keyboard shortcuts** - categories are always one tap away
3. **Don't scroll up/down** - use category sidebar to jump
4. **Cart badge** shows quantity without opening cart

### 💡 Smart Workflow
1. **Ask customer for drink first** - select Beverages category
2. **Then ask for starter** - select Starters category  
3. **Then main course** - select Main Course category
4. All items accumulate in one cart
5. Send all together to kitchen

### ⚡ Quick Add Technique (List View)
```
Customer: "2 Samosas, 1 Paneer Tikka, 3 Rotis"

You:
1. Tap Starters category
2. Tap [+] on Samosa twice
3. Tap [+] on Paneer Tikka once
4. Tap Main Course category
5. Tap [+] on Roti three times
6. Tap "Send to Kitchen"

Done in 5 seconds! ⚡
```

## Troubleshooting

### "I can't see all categories"
- Scroll in the category sidebar (left side)
- Categories area is scrollable if there are many

### "Items are too small in grid view"
- Switch to **List View** using the [☰] button
- List view shows larger thumbnails

### "I added wrong item"
- Scroll to cart at bottom
- Tap **[-]** to decrease quantity
- Or tap again to reach 0 (removes item)

### "Customer changed mind about size"
- Items with sizes can't be edited after adding
- Remove the item (decrease to 0)
- Add again and select correct size

### "Search not finding item"
- Try partial name (e.g., "chick" for "Chicken")
- Or browse by category
- Search works on item name and description
