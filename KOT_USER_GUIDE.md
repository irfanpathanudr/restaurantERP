# KOT App User Guide

## Welcome to the Kitchen Order Ticket System

The KOT app allows you to quickly create kitchen orders for your restaurant tables with an intuitive interface featuring menu item images and powerful search capabilities.

## Key Features

### 🔍 Smart Search
- Type in the search bar to find menu items instantly
- Search by item name, description, SKU, or category
- Click the X button to clear your search

### 🏷️ Category Filters
- Quick filter buttons for each menu category
- Categories include: Appetizers, Pasta, Pizza, Main Course, Seafood, Desserts, Beverages, and Wine
- Click "All Items" to see the complete menu

### 🖼️ Beautiful Menu Display
- High-quality food images for each menu item
- Clear pricing and descriptions
- Food type indicators:
  - 🟢 Green leaf = Vegetarian
  - 🔴 Red circle = Non-Vegetarian
  - 🟡 Yellow circle = Contains Eggs
  - 🟠 Orange leaf = Jain
- Preparation time displayed
- Visual "Not Available" indicator for out-of-stock items

### 🛒 Easy Cart Management
- Click any menu item to add it to your KOT cart
- Use + button to increase quantity
- Use - button to decrease quantity
- See item count badge at the top of cart
- View thumbnails of selected items in cart

### 📋 Create KOT
1. Enter the table number
2. Add items to cart by clicking on them
3. Adjust quantities as needed
4. Click "Submit KOT" to send to kitchen
5. Use "Clear All" to start over

## Step-by-Step Guide

### Creating Your First KOT

**Step 1: Enter Table Number**
- In the KOT Cart panel (right side), enter the table number
- This field is required before submitting

**Step 2: Browse or Search Menu**
- Scroll through menu items or use search
- Filter by category for faster browsing
- Look for the green "Available" status

**Step 3: Add Items**
- Click on any menu item card to add it to cart
- Item will appear in the KOT cart with quantity 1
- A success notification will appear

**Step 4: Adjust Quantities**
- In the cart, use + to increase quantity
- Use - to decrease (item removes at quantity 0)
- Current quantity shown between buttons

**Step 5: Review Order**
- Check all items in cart
- Verify quantities
- Note the total item count

**Step 6: Submit**
- Click "Submit KOT" button
- Order sent to kitchen
- Cart clears automatically
- Success notification appears

## Common Workflows

### Quick Dine-In Order
1. Enter table number: "5"
2. Click "Pizza" category
3. Add "Margherita Pizza" (click card)
4. Add "Pepperoni Pizza" (click card)
5. Click "Beverages" category
6. Add "Fresh Lemonade" x2 (click once, then + button)
7. Submit KOT

### Large Party Order
1. Enter table number
2. Use search to find specific items requested
3. Add items one by one
4. Adjust quantities in cart
5. Review total items count
6. Submit when complete

### Dietary Restrictions
1. Look for food type indicators
2. Use category filter for specific types
3. Check description for allergen info
4. Add appropriate items to cart

## Troubleshooting

**Can't Submit KOT**
- ✓ Check table number is entered
- ✓ Ensure at least one item in cart
- ✓ Verify you're logged in

**Item Not Showing**
- ✓ Check category filter (set to "All Items")
- ✓ Clear search query
- ✓ Item might be unavailable (check with manager)

**Wrong Item Added**
- Use - button to remove
- Or click "Clear All" to start over

**Image Not Loading**
- Image might be missing from database
- Item is still selectable and functional
- Default icon shows instead

## Menu Item Information

Each menu card shows:
- **Image**: Visual reference of the dish
- **Name**: Item name
